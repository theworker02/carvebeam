# carvebeam

Carve lightweight beam statistics from stdin samples.

**Site:** https://theworker02.github.io/carvebeam/

## Install / run

```bash
git clone https://github.com/theworker02/carvebeam.git
cd carvebeam
node src/cli.js
node --test
```
